# DeepSeek 智能会议助手

这是一个基于DeepSeek API的智能会议助手项目，包含四个实验阶段的完整实现。

## 项目结构

- `app/` - Streamlit应用，包含前端和后端模块
- `requirements.txt` - 项目依赖

## 应用模块

### 完整智能会议助手（模块化架构）
- 位置：`app/main.py`
- 架构：`app/backend/`（后端模块）+ `app/frontend/`（前端模块）
- 内容：多轮对话、状态管理、创新功能

## 快速开始

1. **配置环境**：
   ```bash
   # 安装依赖
   pip install -r requirements.txt

   # 配置API Key
   # 编辑 .env 文件，将 your_api_key_here 替换为你的DeepSeek API Key
   ```

2. **运行应用**：
   ```bash
   # 完整智能会议助手（模块化架构）
   streamlit run app/main.py
   ```

## 项目架构

### 模块化设计
- **后端模块** (`app/backend/`)：
  - `ai_service.py` - AI服务（意图识别、会议总结生成）
  - `data_manager.py` - 数据管理（会议室管理、用户管理）
  - `chat_manager.py` - 聊天历史管理
  - `__init__.py` - 模块导出

- **前端模块** (`app/frontend/`)：
  - `login_page.py` - 登录页面
  - `admin_panel.py` - 管理员面板
  - `meeting_page.py` - 会议页面（侧边栏、聊天界面）
  - `__init__.py` - 模块导出

- **主入口** (`app/main.py`) - 整合前后端模块的主程序

### 设计模式
采用 MVC 模式进行架构分离：
- **Model（模型）**：后端模块负责业务逻辑和数据处理
- **View（视图）**：前端模块负责界面展示和用户交互
- **Controller（控制器）**：主入口文件协调前后端交互

## 功能特性

- ✅ **意图识别**：精准识别查询、预约、取消等意图
- ✅ **会议预约**：智能解析时间、人数、会议室信息
- ✅ **状态管理**：实时会议室状态同步
- ✅ **会议总结**：AI生成专业会议纪要
- ✅ **多轮对话**：支持上下文连续对话
- ✅ **异常处理**：友好的错误提示和重试机制
- ✅ **创新功能**：AI性格切换、PDF导出等

## 项目亮点

1. **模块化设计**：后端业务逻辑封装在 `app/backend/` 模块中
2. **渐进式开发**：从简单API调用到完整应用
3. **用户体验**：Streamlit界面美观，交互流畅
4. **错误处理**：完善的异常处理和用户提示
5. **可扩展性**：易于添加新功能和定制化
