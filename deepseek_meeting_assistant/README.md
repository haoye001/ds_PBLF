# DeepSeek 智能会议助手

这是一个基于DeepSeek API的智能会议助手项目，支持**在线体验**和本地运行。采用简约商务风格UI设计，为用户提供专业、高效的会议管理体验。

## 🎨 界面预览

### 核心特性
- 🎨 **简约商务UI**：专业深蓝色调，简洁清爽设计
- 🤖 **智能AI对话**：基于DeepSeek的自然语言处理
- 📅 **会议室管理**：实时状态查询与预约
- 📝 **智能总结**：AI自动生成会议纪要
- 🔐 **安全登录**：多角色权限控制
- 📱 **响应式布局**：适配多种设备

## 项目架构

### 模块化设计
- **后端模块** (`app/backend/`)：
  - `ai_service.py` - AI服务（意图识别、会议总结生成）
  - `data_manager.py` - 数据管理（会议室管理、用户管理）
  - `chat_manager.py` - 聊天历史管理
  - `__init__.py` - 模块导出

- **前端模块** (`app/frontend/`)：
  - `login_page.py` - 登录页面（简约商务风格）
  - `admin_panel.py` - 管理员面板
  - `meeting_page.py` - 会议页面（侧边栏、聊天界面）
  - `__init__.py` - 模块导出

- **主入口** (`app/main.py`) - 整合前后端模块的主程序

### 设计模式
采用 MVC 模式进行架构分离：
- **Model（模型）**：后端模块负责业务逻辑和数据处理
- **View（视图）**：前端模块负责界面展示和用户交互
- **Controller（控制器）**：主入口文件协调前后端交互
